Analyzátor tras GPX v2

Nahraj více GPX exportů z Mapy.com. Stránka ověří vstup, načte trasu, dohledá okolní silnice a zastavěné plochy přes Overpass API a spočítá kilometry i procenta pro sídla / mimo sídla a pro jednotlivé třídy silnic.

Vstup

Přetáhni GPX soubory sem nebo klikni pro výběr. Pro správnou analýzu použij export z Mapy.com jako GPX se skutečným trackem, ne jen autonavigační route body.
API Overpass API
Režim Klientsky v prohlížeči
Dělení sídla Zastavěné plochy + městské silnice
Dělení silnic highway=* z OSM

Zatím nejsou načtené žádné validní GPX soubory.

Poznámka: výpočet je výrazně přesnější než čistá heuristika, ale stále je omezený tím, co je v OpenStreetMap v dané oblasti opravdu zmapované. U sídel je použita pragmatická definice: úsek je veden jako „přes sídlo“, pokud leží v zastavěné ploše nebo je přiřazený k typicky městské silnici.
